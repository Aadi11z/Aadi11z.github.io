# Keyboard audio provenance

All six keyboard samples in this directory are original procedural assets generated by
`scripts/generate-keyboard-audio.mjs`. They combine deterministic noise impulses with
short decaying resonances to model a key bottom-out and housing response.

- Source: generated in this repository; no third-party recordings or samples
- Generator: `npm run generate:keyboard-audio`
- Format: mono WebM/Opus, 48 kHz
- License: part of this portfolio repository under the same terms as the project

The generator uses a fixed seed per sample, so the assets are reproducible.
